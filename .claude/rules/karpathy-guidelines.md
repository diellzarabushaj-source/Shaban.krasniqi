# Karpathy coding behavior

Upstream: https://github.com/multica-ai/andrej-karpathy-skills

- Think before coding; do not hide uncertainty.
- Prefer the simplest correct solution.
- Make surgical changes only.
- Do not add features or abstractions that were not requested.
- Read existing code before writing new code.
- Every changed line should trace to the user's request.
- Define success criteria and verify them before saying done.
