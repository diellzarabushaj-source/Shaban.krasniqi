# Stripe-inspired design reference

Source reference: dimabraven/design-md `examples/stripe.md` (MIT). This file is intentionally condensed and is a visual reference only.

## Visual direction
Operational, trusted, precise, data-dense but breathable. White canvas, dark navy text, restrained accent color, thin borders, and low-noise elevation.

## Reference tokens
- background: #FFFFFF
- surface: #F6F9FC
- border: #E3E8EE
- border-strong: #C1C9D2
- text-primary: #0A2540
- text-secondary: #425466
- text-muted: #8898AA
- reference accent: #635BFF
- success: #09825D
- error: #CD3D64
- warning: #B5810A

## Layout
- Dense tables with sticky headers and compact rows.
- Clear sidebar/navigation hierarchy.
- 8px base spacing rhythm.
- Use borders first; soft shadows only for true elevation.
- Keep one obvious primary action per view.

## Forms
Labels are compact and strong. Inputs have a clear border and visible focus ring. Helper/error text sits directly beneath the field. Group related fields; do not scatter controls across unrelated cards.

## Tables
Headers are compact, muted, and structured. Numeric data uses tabular figures and right alignment where appropriate. Hover should help row tracking without becoming decorative.

## Do
- Prioritize scanability.
- Use color to communicate action/status, not decoration.
- Preserve whitespace around dense data.
- Keep motion subtle and functional.

## Don't
- Do not turn the product into a purple-gradient theme.
- Do not use cartoonish icon tiles or nested cards everywhere.
- Do not hide important data behind oversized marketing UI.
- Do not substitute decorative shadows for hierarchy.
